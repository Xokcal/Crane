Crane
一个用纯 C 语言从零实现的轻量级脚本语言。

项目简介
Crane 是一个使用纯 C 语言实现的轻量级脚本语言，不依赖任何第三方库。项目从词法分析、语法解析到表达式求值与运行时执行全部手工实现，旨在以有限的代码规模，完整呈现编程语言的核心实现机制。

Crane 的设计目标是 可运行、可理解、可扩展：既能实际执行脚本，又保持代码结构清晰，便于学习与二次开发。

已实现功能
词法分析：手写词法扫描器，将源码切分为 Token 序列

语法分析：手写递归下降解析器，构建抽象语法树

表达式求值：支持运算符优先级与括号嵌套

变量与赋值：支持变量定义、赋值与读取

控制流：支持 if、while、for 语句

函数：支持函数定义与调用

内置函数：提供基础 I/O 与标准库函数

错误提示：语法错误与运行时错误的定位与提示
